This repository contains the tasks completed as part of the Codsoft Python Programming virtual internship.
TASKS:
TASK1: TO-DO LIST
A command-line to-do list application that lets users add,view, update and delete tasks.
TASK2: CALCULATOR
A simple calculator that performs basic arithmetic operations(addition,substraction,multiplication,division) based on user input
TASK3: PASSWORD GENERATOR
A script that generates a random, secure password based on user-specified length, using a mix of letters, digits, and symbols. Includes an option to generate multiple passwords in one session.
TASK4: ROCK,PAPER,SCISSORS 
A interactive command-line game where the user plays Rock-Paper-Scissors against the computer. Includes a play-again option to run multiple rounds.
TASK5: CONTACT BOOK
A contact management application that allows users to add, view, search, update, and delete contact entries.
TECH USED: -PYTHON 3.14
